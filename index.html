Chạy thế nào

  1. Nháy đúp cr7.bat → máy hỏi quyền Administrator → Yes.
  2. Gõ ngày khảo sát (ví dụ 18/10/2026 hoặc hom qua) rồi Enter. Enter trắng = hôm nay.
  3. Gõ khung giờ (ví dụ 0800-1700, 8-17, 22-06) rồi Enter. Enter trắng = quét cả ngày.
  4. Đợi ~1–2 phút. Mở thư mục BangChung_<ngay>_<ten may> ở gốc ổ C, đọc file 00_BaoCao_TongHop_*.docx.

Cần biết trước

  • Cần quyền Administrator, không có thì sự kiện log và registry một số mục sẽ trống.
  • Mặc định bỏ qua C:\Windows cho nhanh. Thêm từ full (ví dụ cr7.bat 18/10 full) để quét cả ổ, chậm hơn nhiều lần.
  • ConsoleHost_history.txt chỉ lưu nội dung lệnh, Windows không lưu giờ từng dòng — bằng chứng có giờ thật là UserAssist, event log PowerShell và Security 4688.
  • Muốn thấy tên lệnh trong Security 4688 thì bật audit trước: auditpol /set /subcategory:"Process Creation" /success:enable.
  • File chỉ đọc dữ liệu trên máy đang chạy, không gửi đi đâu. Key được kiểm tra ngay trong trình duyệt bằng WebCrypto, không gọi mạng.

Mã nguồn file nằm trong khối mã hóa — không tải được nếu thiếu key. Trình duyệt hỗ trợ: Chrome, Edge, Cốc Cốc, Firefox 113+, Safari 16.4+.
